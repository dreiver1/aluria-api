# Instruções para agentes

## Documentação obrigatória

Toda tarefa que modificar funcionalidades, comportamento, endpoints, contratos de API, configuração, instalação, dependências relevantes ou fluxos de utilização deverá revisar e atualizar o `README.md` deste repositório.

A documentação faz parte da Definition of Done.

- Atualize o README na mesma tarefa da implementação e inclua-o no mesmo commit.
- Não documente funcionalidades inexistentes como implementadas.
- Não deixe exemplos desatualizados.
- Não invente endpoints, parâmetros ou respostas; confira o código real.
- Diferencie funcionalidades disponíveis, em desenvolvimento e planejadas.
- Mantenha exemplos executáveis e coerentes com a implementação.
- Não exponha credenciais, segredos ou dados reais.
- Se a alteração não exigir atualização documental, registre brevemente a justificativa no relatório final.
